# Pub.dev Explorer

A feature-rich Flutter client application for discovering, searching, and exploring Dart and Flutter packages from pub.dev.

## Features
- **Explore & Search**: Browse top packages, flutter favorites, and search by keyword or tags.
- **Package Details**: View package metadata, publisher info, likes, pub points, and copy install commands (`dart pub add`).
- **Liked Packages**: Bookmark and save your favorite packages locally.
- **Account & Publishers**: View authenticated user profile and publisher organization domains.
